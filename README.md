# Hal9000 Lab website

Landing page: `index.html` (+ `landing.css`).

Each project is a self-contained website in its own folder, with its own `assets/`, styles and scripts. Nothing is shared between projects:

- `GMMIS-Survey/` - Generalist Models in Medical Image Segmentation: A Survey and Performance Comparison with Task-Specific Approaches
- `Awakening-ImageCAS/` - Beyond Segmentation: Enriching ImageCAS with Coronary Ostia Landmarks, Rooted Centerline Graphs, and Open-Weight Localization Models (project name: Awakening ImageCAS)

The top-level `assets/` folder is intentionally empty (reserved for resources of the landing page).

`dev_scripts/` starts a local server (`http://localhost:8000`).
